# 🏛️ Tiles Gallery

A premium architectural platform designed to showcase luxury tiles with a minimalist, high-end aesthetic inspired by **Simpolo Ceramics**. Tiles Gallery offers a sophisticated browsing experience for architects, designers, and homeowners to explore exclusive tile collections.

🔗 **Live Demo:** [tiles-gallery-two.vercel.app](https://tiles-gallery-two.vercel.app)

---

## ✨ Key Features

- 🖤 **Luxury Minimalist UI** — High-contrast, architectural design with a monochrome aesthetic
- 🔐 **Secure Authentication** — Full login & registration system powered by **Better-Auth**
- 🔑 **Social Login** — Seamless **Google OAuth** integration for quick access
- 🖼️ **Dynamic Collections** — Interactive gallery with high-resolution imagery and detailed tile specifications
- 👤 **User Management** — Personal profile dashboard to manage account details and profile imagery
- 🎞️ **Responsive Marquee** — Auto-playing architectural marquee highlighting featured categories
- 🛡️ **Middleware Security** — Protected routing ensures sensitive data is only accessible to authenticated users

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/sarifulrana78/Tiles-gallery.git
cd Tiles-gallery
```

### 2. Install dependencies
```bash
npm install
```

### 3. Set up environment variables
Create a `.env` file in the root with:
```env
MONGODB_URI=
BETTER_AUTH_SECRET=
BETTER_AUTH_URL=

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
```

### 4. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
