# Tiles Gallery

## Purpose
Tiles Gallery is a premium architectural platform designed to showcase luxury tiles with a minimalist, high-end aesthetic inspired by Simpolo Ceramics. The application provides a sophisticated browsing experience for architects, designers, and homeowners to explore exclusive collections.

[Live Project Link](https://tiles-gallery-rana.vercel.app/) *(Placeholder - Replace with your actual deployment URL)*

## Key Features
- **Luxury Minimalist UI**: High-contrast, architectural design with a monochrome aesthetic.
- **Secure Authentication**: Full-featured Login and Registration system using Better-Auth.
- **Social Login**: Seamless Google OAuth integration for quick access.
- **Dynamic Collections**: Interactive gallery with high-resolution imagery and detailed tile specifications.
- **User Management**: Personal profile dashboard to manage account details and profile imagery.
- **Responsive Marquee**: Auto-playing architectural marquee highlighting featured categories.
- **Middleware Security**: Protected routing ensuring sensitive data is only accessible to authenticated users.
